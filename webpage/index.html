いま動いているもの / Running today

稼働中 / live GitHub の aon-co-jp の公開リポジトリを、毎日 04:00(JST)に GitLab (aon-co-jp-group) へ一方向でミラーします。 非公開リポジトリは対象外です。GitHub Actions で動かしており、このリポジトリを公開にしてあるため実行は無料です。
Every day at 04:00 JST, the public repositories of aon-co-jp on GitHub are mirrored one-way to GitLab. Private repositories are not included. It runs on GitHub Actions, which is free because this repository is public.

これから作るもの / What is being built

「全部を丸ごと」ではなく、本当に必要な最小限のデータだけを厳選してバックアップします。 厳選するための一覧(リスト)を用意し、残す・最新だけ残す・捨てるを選べるようにします。
Instead of copying everything, keep only the data that really matters, chosen from a curation list (keep / latest only / skip).
