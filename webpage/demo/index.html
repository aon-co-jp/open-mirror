open-mirror デモ / demo

これは説明用のデモです。表のデータは架空のサンプルで、あなたのファイルは一切読みません。すべてこのブラウザの中だけで動き、何も送信しません。実際のバックアップは行いません。
This is an illustration. The data below is made up; your files are never read, nothing is uploaded, and no real backup is made.

1. 厳選リスト Curation list

各行の「印」を選ぶと、バックアップされる合計の大きさが変わります。 Change the mark per row and watch the total.

バックアップ元
source		項目
item		容量
size		再取得
re-creatable		印
mark
選んだ合計 / Selected total: 0

◎=最新だけ残す ○=世代を絞って残す △=要確認(今は含めない) ×=バックアップしない。 ◎ latest only, ○ a few generations, △ undecided (excluded), × skip.




2. 圧縮と展開 Compress and extract


上のリストを、ブラウザの機能(gzip)で実際に圧縮し、展開して元に戻ることを確かめます。 Really compresses the list with gzip, then extracts it and checks it matches.







3. 暗号化と復号 Encrypt and decrypt


パスフレーズから鍵を作り(PBKDF2)、AES-256-GCM で暗号化し、同じパスフレーズで復号します。パスフレーズは保存も送信もしません。 Key from a passphrase (PBKDF2), AES-256-GCM. The passphrase is never stored or sent.



  
  






4. ネットに繋がったら開始 Start when online


スマホ・タブレット・PC は、ネットに繋がった瞬間にバックアップを始めます。ここではブラウザの接続状態の変化を見て、始まる様子を模擬します(機内モードやWi-Fiの切断→再接続を試せます)。

Devices start when they come online. This watches your browser's connection state and simulates the start (try toggling airplane mode / Wi-Fi).
